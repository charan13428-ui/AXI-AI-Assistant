AXI – AI Android Assistant

Your Personal Smart Assistant

AXI is an AI-powered Android assistant designed to make everyday mobile tasks easier through voice commands in English and Tamil.

Features

- English and Tamil voice interaction
- Voice command recognition
- Smart AI conversations
- Permission-based Android controls
- App launching
- Battery and device information
- Privacy-focused security
- User-controlled permissions

Security

- No hidden access
- No unauthorized actions
- User approval for sensitive permissions
- Secure handling of personal data

Project Goal

To build a powerful, intelligent and secure Android assistant.

Languages

- English
- Tamil

Project Name: AXI
Platform: Android
